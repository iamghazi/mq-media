# mq-media

Public hosting for Math Quotient media. Buffer and WordPress read each file through its raw.githubusercontent.com link.

Layout:
- `reels/<YYYY-MM-DD>/<name>.mp4` (date = planned post date). Master copies live in Google Drive.
- `blog/<YYYY-MM-DD>/<keyphrase-slug>.png`: featured images for Math Topics blog posts, 1200 x 630 (date = draft date). WordPress copies each image into its media library, so the file here is only the source.
- `carousels/<YYYY-MM-DD>/<student>/slide1.jpg ... slide6.jpg` + `caption.txt`: Instagram student-story carousels, 1080 x 1350 (date = planned post date, one a week).
